# نظام الكاشير - دوار العمده

نظام كاشير كامل يعمل على الشبكة المحلية مع دعم الطباعة والإدارة.

## المميزات

- ✅ صفحة كاشير سريعة وحديثة
- ✅ صفحة تابلت للطهاة والنوادل
- ✅ صفحة إدارة كاملة
- ✅ دعم الطباعة (ESC/POS)
- ✅ تقارير يومية وشهرية
- ✅ يعمل على الشبكة المحلية
- ✅ تحويل إلى ملف EXE

## التثبيت

### التثبيت العادي

1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

2. تشغيل النظام:
```bash
python main.py
```

3. فتح المتصفح على: `http://localhost:3000`

### بناء ملف EXE

1. تشغيل ملف البناء:
```bash
build_exe.bat
```

2. ملف EXE سيكون في مجلد `dist`

## الاستخدام

### صفحة الكاشير (الافتراضية)
- إضافة منتجات للطلب
- طباعة تذكرة المطبخ
- إكمال الطلب وطباعة الفاتورة

### صفحة التابلت (`/tablet`)
- إضافة منتجات وإرسال الطلب
- الطلب يظهر تلقائياً في الكاشير

### صفحة الإدارة (`/admin`)
- كلمة المرور الافتراضية: `admin123`
- إدارة الفئات والمنتجات
- التقارير والإعدادات

## الإعدادات

في صفحة الإدارة يمكنك:
- تغيير كلمة مرور الإدارة
- إعداد عنوان IP الطابعة

## الشبكة المحلية

النظام يعمل على `0.0.0.0:3000` مما يسمح بالوصول من أي جهاز على نفس الشبكة.

استخدم IP الجهاز للوصول من أجهزة أخرى:
```
http://<ip-address>:3000
```

## قاعدة البيانات

قاعدة البيانات SQLite محلية في ملف `cashier.db`

## الطباعة

النظام يدعم طابعات ESC/POS على الشبكة. قم بإعداد IP الطابعة من صفحة الإدارة.
