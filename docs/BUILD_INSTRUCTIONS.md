# دليل بناء ملف EXE - Build EXE Instructions

## 📋 المتطلبات (Requirements)

1. **Python 3.10+** مثبت على الجهاز
2. **pip** محدث

---

## 🔧 خطوات البناء (Build Steps)

### 1. تثبيت المتطلبات

```bash
pip install -r requirements_build.txt
```

### 2. تنظيف قاعدة البيانات (اختياري)

إذا كنت تريد نسخة نظيفة بدون بيانات:

```bash
cd backend
python reset_orders.py
```

### 3. بناء ملف EXE

```bash
python build_exe.py
```

### 4. النتيجة

بعد اكتمال البناء، ستجد:
- **dist/DawarElOmda.exe** - الملف التنفيذي النهائي
- **اسم التطبيق:** دوار العمده
- **الأيقونة:** لوجو التطبيق

---

## 📦 توزيع التطبيق

### للمستخدم النهائي:

1. **انسخ الملف:**
   - `dist/CashierSystem.exe`

2. **شغّل الملف:**
   - اضغط مرتين على `CashierSystem.exe`
   - سيفتح التطبيق تلقائياً
   - سيفتح المتصفح تلقائياً

3. **لا يحتاج:**
   - ❌ Python مثبت
   - ❌ أي إعدادات إضافية
   - ❌ أي ملفات أخرى

---

## ✅ المميزات

- ✅ **تشغيل تلقائي:** يفتح السيرفرات تلقائياً
- ✅ **اكتشاف تلقائي:** يكتشف IP الشبكة تلقائياً
- ✅ **عرض IP:** يظهر IP في صفحة الأدمن
- ✅ **Responsive:** يعمل على جميع الأجهزة
- ✅ **نسخة نظيفة:** يبدأ من رقم 1 للطلبات والفواتير

---

## 🔍 استكشاف الأخطاء

### المشكلة: فشل البناء

**الحل:**
```bash
pip install --upgrade pyinstaller
pip install --upgrade setuptools
```

### المشكلة: الملف كبير جداً

**الحل:**
- هذا طبيعي، الملف يحتوي على Python وكل المكتبات
- الحجم المتوقع: ~100-200 MB

### المشكلة: التطبيق لا يفتح

**الحل:**
1. تأكد من أن Windows Defender لا يحجبه
2. أضف استثناء في Windows Defender
3. جرب تشغيل كـ Administrator
