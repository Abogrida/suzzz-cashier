# ⚡ دليل البدء السريع - Quick Start Guide

## 🚀 بناء ملف EXE (Build EXE)

### الخطوة 1: تثبيت المتطلبات
```bash
pip install -r requirements_build.txt
```

### الخطوة 2: تنظيف قاعدة البيانات (للنسخة النظيفة)
```bash
cd backend
python reset_orders.py
cd ..
```

### الخطوة 3: بناء EXE
```bash
python build_exe.py
```

### الخطوة 4: النتيجة
- الملف: `dist/DawarElOmda.exe`
- اسم التطبيق: **دوار العمده**
- الأيقونة: لوجو التطبيق
- الحجم: ~100-200 MB
- جاهز للتوزيع!

---

## 📦 استخدام EXE

### للمستخدم النهائي:
1. **اضغط مرتين** على `CashierSystem.exe`
2. **سيفتح التطبيق تلقائياً**
3. **سيفتح المتصفح تلقائياً**

### لا يحتاج:
- ❌ Python
- ❌ أي إعدادات
- ❌ أي ملفات أخرى

---

## 🌐 الوصول من أجهزة أخرى

1. افتح **صفحة الأدمن**
2. ستجد **IP الشبكة** في الأعلى
3. من أي جهاز على نفس الشبكة:
   - الكاشير: `http://[IP]:3000/cashier`
   - التابلت: `http://[IP]:3001/tablet`
