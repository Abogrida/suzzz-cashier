# دليل التثبيت - نظام الكاشير

## المتطلبات
- Python 3.8 أو أحدث
- Windows 10/11

## خطوات التثبيت

### 1. تثبيت Python
إذا لم يكن Python مثبتاً:
- حمّل من [python.org](https://www.python.org/downloads/)
- تأكد من تحديد "Add Python to PATH" أثناء التثبيت

### 2. تثبيت المتطلبات
افتح PowerShell أو CMD في مجلد المشروع وقم بتشغيل:
```bash
pip install -r requirements.txt
```

### 3. تهيئة البيانات
(اختياري) لتعبئة قاعدة البيانات بمنتجات تجريبية:
```bash
python backend/init_sample_data.py
```

### 4. تشغيل النظام
```bash
python main.py
```
أو استخدم:
```bash
start.bat
```

### 5. الوصول للنظام
- الكاشير: http://localhost:3000
- التابلت: http://localhost:3000/tablet
- الإدارة: http://localhost:3000/admin (كلمة المرور: admin123)

## بناء ملف EXE

1. تثبيت PyInstaller:
```bash
pip install pyinstaller
```

2. تشغيل ملف البناء:
```bash
build_exe.bat
```

3. ملف EXE سيكون في مجلد `dist/cashier.exe`

## الشبكة المحلية

للوصول من أجهزة أخرى على نفس الشبكة:
1. افتح النظام على الجهاز الرئيسي
2. انسخ IP الذي يظهر في الكونسول
3. من أي جهاز آخر، افتح: `http://<IP>:3000`

## استكشاف الأخطاء

### المشكلة: لا يمكن الوصول من أجهزة أخرى
- تأكد من إيقاف جدار الحماية أو السماح للمنفذ 3000
- تأكد من أن جميع الأجهزة على نفس الشبكة

### المشكلة: خطأ في الطباعة
- تأكد من إعداد IP الطابعة في صفحة الإدارة
- تأكد من أن الطابعة متصلة بالشبكة
- تأكد من أن الطابعة تدعم ESC/POS

### المشكلة: قاعدة البيانات فارغة
- قم بتشغيل `python backend/init_sample_data.py` لإضافة منتجات تجريبية
- أو أضف المنتجات يدوياً من صفحة الإدارة
