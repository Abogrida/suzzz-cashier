## 📋 المتطلبات الأساسية

### 1. الطابعة الحرارية
- ✅ يجب أن تدعم **ESC/POS** (معظم الطابعات الحرارية تدعمه)
- ✅ يجب أن تكون موصلة بـ **USB** ومثبتة في Windows

### 2. تثبيت pywin32 (مهم جداً!)
للحصول على أفضل أداء مع الطابعات الحرارية USB:
```bash
pip install pywin32
```

**لماذا؟**
- ✅ `pywin32` يسمح بإرسال **RAW data** مباشرة للطابعة
- ✅ بدون `pywin32`، الكود يستخدم أمر `print` الذي قد لا يعمل بشكل مثالي
- ✅ مع `pywin32`، الطباعة تعمل **100%** مع الطابعات الحرارية

## 🔧 كيف يعمل الكود

### الطريقة الأولى: RAW Printing (الأفضل) ✅
إذا كان `pywin32` مثبت:
1. ✅ يفتح الطابعة في **RAW mode**
2. ✅ يرسل **ESC/POS commands** مباشرة
3. ✅ **يعمل 100%** مع الطابعات الحرارية

### الطريقة الثانية: Print Command (بديل)
إذا لم يكن `pywin32` مثبت:
1. ⚠️ يستخدم أمر `print` في Windows
2. ⚠️ قد يمرر البيانات عبر driver الطابعة
3. ⚠️ قد لا يعمل بشكل مثالي مع بعض الطابعات
