# 🚀 دليل بناء ملف EXE - Complete EXE Build Guide

## 📋 المتطلبات (Requirements)

1. **Python 3.10+** مثبت على الجهاز
2. **pip** محدث
3. **Windows 10/11** (للبناء)

---

## 🔧 خطوات البناء (Build Steps)

### 1. تثبيت المتطلبات

```bash
pip install -r requirements_build.txt
```

### 2. تنظيف قاعدة البيانات (للنسخة النظيفة)

```bash
cd backend
python reset_orders.py
cd ..
```

### 3. بناء ملف EXE

```bash
python build_exe.py
```

### 4. النتيجة

بعد اكتمال البناء (قد يستغرق 5-10 دقائق):
- **dist/DawarElOmda.exe** - الملف التنفيذي النهائي (~100-200 MB)
- **اسم التطبيق:** دوار العمده
- **الأيقونة:** لوجو التطبيق

---

## 📦 توزيع التطبيق

### للمستخدم النهائي:

1. **انسخ الملف فقط:**
   - `dist/CashierSystem.exe`

2. **شغّل الملف:**
   - اضغط مرتين على `CashierSystem.exe`
   - سيفتح التطبيق تلقائياً
   - سيفتح المتصفح تلقائياً على `http://localhost:3000`

3. **لا يحتاج:**
   - ❌ Python مثبت
   - ❌ أي إعدادات إضافية
   - ❌ أي ملفات أخرى
   - ❌ أي معرفة تقنية

## 🌐 الوصول من الأجهزة الأخرى

### من نفس الشبكة (WiFi/LAN):

1. **افتح صفحة الأدمن** في التطبيق
2. **ستجد IP الشبكة** في الأعلى (مثال: `192.168.1.100`)
3. **من أي جهاز على نفس الشبكة:**
   - الكاشير: `http://192.168.1.100:3000/cashier`
   - التابلت: `http://192.168.1.100:3001/tablet`
   - الأدمن: `http://192.168.1.100:3000/admin`

### ملاحظة مهمة:
- **IP ثابت للصفحات:** IP التابلت والكاشير لا يتغير
- **IP ديناميكي للعرض:** IP المعروض في صفحة الأدمن يتحدث تلقائياً

## 🔍 استكشاف الأخطاء

### المشكلة: فشل البناء

**الحل:**
```bash
pip install --upgrade pyinstaller
pip install --upgrade setuptools
python -m pip install --upgrade pip
```

### المشكلة: الملف كبير جداً

**الحل:**
- هذا طبيعي، الملف يحتوي على Python وكل المكتبات
- الحجم المتوقع: ~100-200 MB
- يمكن ضغطه بـ 7-Zip لتقليل الحجم

### المشكلة: التطبيق لا يفتح

**الحل:**
1. تأكد من أن Windows Defender لا يحجبه
2. أضف استثناء في Windows Defender
3. جرب تشغيل كـ Administrator
4. تحقق من Windows Event Viewer للأخطاء

### المشكلة: السيرفرات لا تبدأ

**الحل:**
1. تأكد من أن المنافذ 3000 و 3001 غير مستخدمة
2. أغلق أي تطبيقات تستخدم هذه المنافذ
3. أعد تشغيل التطبيق

### المشكلة: لا يمكن الوصول من أجهزة أخرى

**الحل:**
1. تأكد من أن جميع الأجهزة على نفس الشبكة
2. تأكد من أن Firewall لا يحجب المنافذ
3. جرب ping للـ IP من الجهاز الآخر
